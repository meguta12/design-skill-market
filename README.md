# Design Skill Market

「好きなデザインを選ぶだけで、Claude がそのデザインを正確に作れるようになる」デザインスキル配布プラットフォームのプロトタイプ。

配布するのは画像やHTMLではなく **スキルファイル（.md）**。配色・余白・レイアウトの数値ルールと崩れ防止チェックリストが書かれており、Claude に渡すとそのデザインを高い精度で再現できる。

## 機能

- **デザインギャラリー** — 6種類のサンプルデザイン（コーポレート / SaaS LP / 和モダン / ポートフォリオ / クリニック / カフェ）。サムネイルは画像不使用、CSSで描画
- **スキルダウンロード** — 各デザインの詳細ページから `.md` スキルを無料ダウンロード
- **レビュー・星評価** — 星1〜5とコメントを投稿、平均評価がカードに反映
- **クリエイタープロフィール** — 各デザインに投稿者を表示（DOVA-SYNDROME方式）。プロフィールにはホームページ / X / Instagram / YouTube のリンク、投稿数、累計DL数
- **アカウント作成** — 表示名・自己紹介・SNSリンクを登録（現状はlocalStorage保存の仮実装）
- **デザイン投稿** — アカウント作成済みなら誰でも投稿可能。サムネイルは選択した2色から自動生成。スキル本文のテンプレート付き
- **制作代行の依頼フォーム** — 送信すると内容が自動入力された相談メールが作成される

## 動かし方

ビルド不要の静的サイト。フォルダ内で適当なHTTPサーバーを立てるだけ。

```bash
python3 -m http.server 4173
# → http://localhost:4173
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 全ビュー（ギャラリー / 詳細 / クリエイター / アカウント / 投稿） |
| `styles.css` | 全スタイル |
| `data.js` | デザインカタログ・スキル本文・クリエイターのシードデータ |
| `app.js` | ビュー切り替え・レビュー・投稿・アカウント・ダウンロードのロジック |

## 現状の制約（プロトタイプ）

- アカウント・投稿・レビュー・DL数増分は **localStorage 保存**。ユーザー間で共有されない
- 依頼フォームは mailto 方式

## 次のステップ候補

1. Supabase で認証（Googleログイン＋マジックリンク）とデータベースを導入し、投稿・レビューを全ユーザー共有に
